# 分析方法论

**核心逻辑**：研报一致预期作**基准**，离散专家纪要作**修正**，赚的是**修正值本身**。

- 收入预测：从"研报平均"升级为"指引偏差校准 + 分部驱动"。
- 利润预测：从"净利率外推"升级为"可审计财务桥 + 一次性项目概率"。
- 弱证据分档处理，不制造伪精确：
  | 证据等级 | 处理 |
  |---|---|
  | 已签约/已出货/量价明确 | 可量化进点预测 |
  | 已认证/明确量产但基数不清 | 调 Bull/Base/Bear 权重 |
  | 管理层措辞/渠道传闻 | 只列观察项 |
  | 已被指引或研报吸收 | 修正值=0 |
  概率用 5 个百分点为最小变化单位。

**为什么**：alpha 来自专家纪要的修正，不来自更精的统计模型。所以纪律/护栏/反馈优先于建模。

**在哪执行**：`config/prompts/instructions.md` 原则9-11；研报骨架 `config/prompts/report_skeleton.md`（券商预测表→纪要修正因子表→修正后业绩表）。
