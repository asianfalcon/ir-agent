# AMD（AMD）研究报告：2026Q2前瞻与2026—2028年预测

**报告日期：2026年7月14日｜评级：中性/持有｜IRA核心预测：2026Q2收入113.0亿美元，Non-GAAP EPS 1.62美元**

> 数据优先级：IRA MCP → IRA本地SQLite与清洗后的AMD官方/券商原文 → 本地缺失时使用网络一致预期。公司实际值、公司指引、卖方一致预期和IRA修正四层隔离；公司指引不参与卖方均值。

## 核心判断

AMD基本面强，但当前股价已提前交易MI450/Helios与服务器CPU的2026H2—2027年放量。IRA预测2026Q2收入 **113.0亿美元**，同比 **🔼47.0%**、环比 **🔼10.2%**；Non-GAAP毛利率 **56.0%**，Non-GAAP净利润 **26.87亿美元**，Non-GAAP EPS **1.62美元**。

Q2收入较公司112亿美元指引中值 **+1.0亿美元 🔼0.9%**，较最新市场一致预期112.8亿美元 **+0.2亿美元 🔼0.2%**。利润端的修正更明确：按公司提供的收入、56%毛利率、33亿美元运营费用、0.6亿美元其他收益、13%税率及16.6亿股，指引中值隐含Non-GAAP EPS约1.59美元；IRA收入预测对应EPS约1.62美元，高于市场1.55美元预期。

年度层面，IRA预测2026—2028年收入 **498.0/771.0/1,000.0亿美元**，Non-GAAP EPS **7.50/13.30/17.30美元**。2026—2027年基本贴近7月最新S&P Global共识；2028年采用本地最新券商模型中位数约1,000亿美元作为情景锚点。**结论是“业绩小幅超预期、估值已充分反映”，维持中性/持有。**

### 口径校验

- AMD财季与自然季度基本对齐；SQLite中的2025Q4和2026Q1均为单季度口径，不能将Q4误当全年。
- 2025全年收入346.39亿美元，本地AMD公告与交银国际、第一上海、国泰海通等券商历史表一致；2026Q1收入102.53亿美元也与SQLite和公司公告一致，全年基数校验通过。
- 公司只直接指引Q2收入和Non-GAAP毛利率，未直接给EPS。隐含EPS计算为：112亿美元 × 56%毛利率 − 33亿美元Non-GAAP运营费用 + 0.6亿美元其他收益 = 30.32亿美元税前利润；按13%税率及16.6亿股折算约 **1.59美元/股**。这是IRA测算，不是公司明示EPS指引。
- 2025Q2收入为76.85亿美元；IRA的113.0亿美元预测对应同比 **🔼47.0%**，不能用2026Q1作为同比基数。
- MCP `earnings_forecast`未召回本地已存在的Q2数字指引，并将单一卖方全年预测按30%分配为Q2约129.37亿美元；该方法绕开公司109—115亿美元指引，故不采用。

### 年度Sanity Check

IRA 2026年收入498.0亿美元，在Q1实际102.53亿美元及Q2预测113.0亿美元之后，H2仍需282.47亿美元，即Q3/Q4平均141.24亿美元，较Q2高 **25.0%**。该斜率需要MI450/Helios从Q3开始交付并在Q4明显爬坡，符合本地券商共同假设，但不是无条件线性增长。

华泰2026年638.92亿美元则要求H2实现423.39亿美元，即Q3/Q4平均211.70亿美元，较Q2高 **87.3%**；现有本地证据无法证明H2连续两个季度达到这一台阶，因此只作为Bull case，不作为基准预测。
