超威半导体 (AMD)：智能体 AI 驱动服务器 CPU 增长，数据中心 GPU 长期前景看涨 Goldman Sachs Research Advanced Micro Devices Inc. (AMD): Upgrade to Buy as Agentic AI drives server CPU tailwinds; we see datacenter GPU upside in 2027 & beyond 2026年5月5日 执行摘要 本报告将超威半导体（AMD）的股票评级上调至“买入”，并设定 12 个月目标价为 450 美元。这一转变的核心逻辑在于智能体 AI（Agentic AI）的兴起正成为公司服务器 CPU 业务的强劲结构性利好。随着 AI 工作负载向推理侧转移，服务器 CPU 的使用量将显著增加。此外，本报告预测 AMD 在数据中心 GPU 领域（尤其是 2027 年及以后）具有显著的上行空间，这主要得益于与 Meta 等大客户的战略部署。尽管 Broadcom 和 Nvidia 在相对基础上仍是首选，但 AMD 在服务器 CPU 领域为投资者提供了参与智能体 AI 浪潮的独特机会。预计到 2027 年，数据中心业务将占公司总营收的 75% 以上。 智能体 AI 驱动的服务器 CPU 结构性利好 智能体 AI 的演进正在改变计算资源的分配模式，从单纯的训练转向更大规模的推理工作负载。这种转变对服务器 CPU 市场具有深远影响： 计算需求的变化：基于智能体的系统需要 CPU 处理更多的“思考”、数据路由和工具调用，并在整个网络中协调工作负载。 Token 消费的激增：预计到 2030 年，与智能体 AI 相关的 Token 将占总量的 90%，其中企业端占 50%，消费端占 40%。到 2030 年，全球 Token 消耗量可能比 2026 年的预估容量增长 24 倍以上。 x86 架构的持久力：在企业级智能体 AI 领域，x86 架构因其与现有企业基础设施的互操作性而具有极强的生命力。相比之下，消费级 AI 智能体可能更倾向于基于 ARM 的 CPU。 营收预测：预计 2027 年和 2028 年的服务器 CPU 营收将分别达到 211 亿美元和 274 亿美元，比市场共识预期高出 24% 和 38%。 服务器 CPU 业务的五大增长因子 AMD 在服务器 CPU 领域的领先地位受到以下五个关键因素支撑： AI 服务器中 CPU 附着率提高：GPU 与 CPU 的附着率已从 8:1 演变为最新机架配置中的 2:1。随着行业向 CPU 专用机架发展，这一趋势有望延续。 加速器业务的联动效应：预计从 2026 年下半年开始，AMD 数据中心 GPU 出货量将强劲增长，而 AMD 的 AI 机架往往会配备更高比例的自家 CPU。 企业数据中心现代化：企业正在通过刷新 CPU 阵列来优化空间和功耗。智能体 AI 的部署将推动现有 CPU 架构的升级需求。 核心数量增加带动平均售价（ASP）：智能体 AI 工作负载提升了对核心利用率和性能的要求。随着行业向新一代产品过渡，CPU 单元数量和 ASP 均有上行空间。 市场份额的持续扩张：AMD 有望在服务器 CPU 市场（尤其是企业端）继续获取增量份额。 数据中心 GPU 的上行潜力 报告对 AMD 数据中心 GPU 的营收前景持乐观态度，特别是在 2027 年之后： Meta 战略伙伴关系：AMD 与 Meta 的 6GW 部署机会是最大的看点。该协议包含 1.6 亿股 AMD 股票期权，根据里程碑达成情况分批归属。 客户多元化： Meta：预计部署规模将从 2026 年的 0.25GW 增长到 2030 年的 1.65GW。 Microsoft：预期份额保持稳定，营收增长与微软的总资本支出增长同步。 OpenAI：采取较谨慎的建模方式，预计到 2030 年将部署约 2GW 的容量。 营收预期：预测 2027 年和 2028 年数据中心 GPU 营收分别为 425 亿美元和 563 亿美元，比市场预期分别高出 28% 和 26%。 传统业务的周期性风险已基本被市场消化 AMD 的非 AI 业务虽然面临挑战，但这些负面因素已被充分定价： 个人电脑（PC）业务：由于内存价格驱动的需求破坏以及企业换机周期消退，PC 市场短期承压。预计 2026 年全球 PC 出货量将下降 10%，2027 年起小幅复苏。到 2027 年，客户端业务营收占比将降至 14% 左右。 游戏业务：目前正处于游戏机周期的后期，预计到 2027 年该板块占总营收比例将不足 5%。 嵌入式业务：目前处于上行周期的早期阶段，其复苏将对公司未来的营收和毛利率产生积极贡献。 核心风险因素 智能体 AI 采用速度慢于预期：如果消费者和企业对 AI 智能体的采纳不及预期，将直接影响 CPU 估算。 Meta 交易执行风险：Meta 是 GPU 营收的关键贡献者，任何由于供应链或 AI 需求下降导致的部署放缓都将构成下行风险。 架构竞争：ARM 架构在企业级市场如果实现超预期渗透，可能会侵蚀 x86 的份额。 运营杠杆缺失：如果运营支出（OpEx）高于预期，可能导致利润率扩张速度放缓。 股价估值与财务预测 目标价与评级： 12个月目标价：从 240 美元上调至 450 美元（较当前股价约有 27% 的上行空间）。 估值方法：基于 30 倍的市盈率（P/E）倍数，应用于 15.00 美元的标准化每股收益（EPS）估计。由于数据中心营收能见度提高，P/E 倍数从先前的 28 倍上调。 关键财务数据预测（2027E / 2028E）： 总营收：预计 2027 年为 833.01 亿美元（高出市场共识 21%），2028 年为 1045.99 亿美元（高出共识 20%）。 每股收益 (非 GAAP，不含 SBC)：预计 2027 年为 13.50 美元，2028 年为 18.00 美元，均比市场共识高出约 20%。 毛利率 (不含 SBC)：预计 2027 年为 53.7%，2028 年为 54.2%。虽然数据中心 GPU 快速增长可能对毛利率造成短期压制（略低于市场预期），但服务器 CPU 营收的增加将提升整体运营杠杆。 板块营收构成预测： 数据中心：2027 年占比 77%，2028 年占比 80%。 客户端（PC）：2027 年占比 14%，2028 年占比 12%。 游戏：2027 年占比 4%，2028 年占比 3%。 嵌入式：2027 年占比 5%，2028 年占比 4%。 近期业绩表现： AMD 第一季度财报显示营收 102.5 亿美元（高于预期的 99 亿美元），非 GAAP 每股收益 1.37 美元（高于预期的 1.29 美元）。第二季度营收指引中位数为 112 亿美元，远高于市场预期的 105 亿美元，反映出强劲的业务势头。
